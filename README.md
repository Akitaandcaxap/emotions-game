### 🕹️ О проекте
Простой и залипательный проект, написанный для весёлого времяпрепровождения в браузере. Экспериментируй с сочетаниями эмоций и открывай новые комбинации!

### 🛠️ Стек технологий
* **HTML5 / CSS3** — интерфейс и стилизация
* **JavaScript** — игровая логика
